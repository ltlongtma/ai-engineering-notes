## Summary

This file lists the agent skills that the owner uses, with the opinion of the owner.

## Tools

### Archify

- Type: skill
- Link: https://github.com/tt-a1i/archify
- Use for: Make interactive architecture, workflow, and sequence diagrams as one HTML file.
- Status: using
- My verdict: Makes clean architecture diagrams as one HTML file; I use it for the overview map.

### Superpowers

- Type: skill
- Link: https://github.com/obra/superpowers
- Use for: Run a set development workflow with composable skills: brainstorm, spec, plan, execute, and review.
- Status: using
- My verdict: My default workflow: brainstorm, spec, plan, then execute with a review at the end.

### ponytail

- Type: skill
- Link: https://github.com/DietrichGebert/ponytail
- Use for: Make the agent write the simplest solution that works, with no abstractions that the user did not ask for.
- Status: using
- My verdict: Stops the agent from adding abstractions that nobody asked for.
